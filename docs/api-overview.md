# Public API overview (`rivulet-core`)

The M8 exit evidence asks for a stability overview of the public modules that
is **generated from the codebase**, so it cannot describe a surface the crate
does not have. This document is that overview: everything between the markers
below is written by

```sh
python3 scripts/generate-api-overview.py
```

and checked in CI (and by the pre-push fast-guard stage) with

```sh
python3 scripts/generate-api-overview.py --check
```

`--self-test` exercises the generator against a fixture crate, including the
two drift cases that matter: a new `pub mod` the document does not list, and a
re-export that disappeared.

## How to read it

- **Public modules** — the `pub mod` list from `rivulet-core/src/lib.rs`, sorted.
  The summary is the first line of each module's own `//!` doc comment, and the
  item count is the number of top-level `pub` items in that file. A module whose
  count is `-` is declared in `lib.rs` without a source file next to it.
- **Re-exported from the crate root** — `yes` means a `pub use` in `lib.rs`
  lifts names out of that module, so a consumer reaches them as
  `rivulet_core::Name` rather than `rivulet_core::module::Name`. The
  **Crate-root re-exports** table lists those names explicitly. That table is
  the surface `docs/m8-api-contract.md` and the `api_stability` guard cover;
  `no` marks modules that are public but not part of that documented set.
- **Modules whose own documentation calls them experimental** — a module is listed
  here when its own doc comments contain an experimental marker (`experimental`,
  `unstable`, `not stable`, `subject to change`), with the file and line as
  evidence. Such a module is **not** covered by the 1.0 stability promise, no
  matter what the milestone prose elsewhere says.
- **`#![warn(missing_docs)]`** — whether the crate really carries the lint as a
  crate attribute. `lib.rs` contains the line as a doc-comment example, which
  enables nothing; the generated state is read from the attribute, not from the
  prose.

## Scope and limitations

This overview reports the shape of the surface, not its quality. It says that a
module is public and whether it is re-exported; it does not say that every
public item is documented, and it is not a semver guarantee on its own — the
promise lives in `docs/m8-api-contract.md`, and the guard that enforces it is
`rivulet-core/tests/api_stability.rs`.
