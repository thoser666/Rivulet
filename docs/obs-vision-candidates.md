# OBS features aligned with the Rivulet vision

This file is maintained by the OBS upstream workflow. It records candidates
classified as `strong-fit` by `scripts/check-obs-upstream.py` and is intentionally
separate from the committed roadmap: a maintainer must review a candidate before
assigning it to a milestone or marking it as implemented.

## Review policy

A candidate is a strong fit when it matches at least two pillars in
[`scripts/vision-criteria.json`](../scripts/vision-criteria.json). The automatic
classification is keyword-based triage, not product approval. Reviewers should
consider feasibility, duplication with existing work, privacy, platform scope,
and testability before updating the README or creating an issue.

## Workflow

The current report is generated by:

```bash
python3 scripts/check-obs-upstream.py --fixture scripts/obs-upstream-fixture.json
```

The weekly GitHub Actions run uploads the full report as `obs-upstream-report`.
Only reviewed candidates should be copied into the roadmap and parity checklist.
