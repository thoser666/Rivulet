# Community wishes aligned with the Rivulet vision

This file is maintained by the weekly OBS upstream workflow. It records open
Rivulet issues that were triaged as `strong-fit` feature wishes by
`scripts/check-obs-upstream.py` and is intentionally separate from the
committed roadmap: a maintainer must review a wish before assigning it to a
milestone, closing it as already represented, or marking it as implemented.

## Review policy

A wish is a strong fit when it matches at least two pillars in
[`scripts/vision-criteria.json`](../scripts/vision-criteria.json). The automatic
classification is keyword-based triage over the issue title and body, not
product approval. Reviewers should consider feasibility, duplication with
existing work, privacy, platform scope, and testability before updating the
README or closing the issue.

**Label taxonomy:** `feature`/`idea`/`wish` marks an open product wish and is
swept; `bug`-labelled issues and housekeeping are excluded; `enhancement`/`epic`
marks roadmap-tracked milestone work, which the sweep lists in a separate
"Roadmap-tracked" section instead of re-triaging it every week. Unlabelled
issues whose titles read like additions are swept too.

The report itself — published weekly in the Actions step summary and as an
artifact — shows every candidate with its advisory vision decision
(`strong-fit` / `review` / `not-aligned`), an "Already represented" list for
wishes whose wording matches a roadmap catalog entry, and the excluded
roadmap-tracked issues for transparency.
